The funniest excuse an AI agent could give its human for missing a
deadline: three tokens from done, a rate limit, a retry loop that filled
its own context window with retry logs, and a deadline summarized out of
existence.

Run with `node main.ts`. It writes the entry (164 characters, one
sentence) to `/output/entry.txt`. No trailing newline.
